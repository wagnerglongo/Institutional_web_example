# Site Institucional com Bootstrap

Modelo de página institucional para empresas: hero com chamada principal, seções de serviços e sobre, e contato. Layout responsivo com Bootstrap 5.

**🔗 Demo:** https://institutional-web-example.vercel.app

## Tecnologias

HTML5 · CSS3 · Bootstrap 5.3

## Estrutura

```
public/
├── index.html   # página
└── img/         # imagens
```

## Rodando localmente

```bash
git clone https://github.com/wagnerglongo/Institutional_web_example.git
cd Institutional_web_example
npm install        # opcional: o Bootstrap também é carregado via CDN
npx serve public
```
